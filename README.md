# 📊 股票看板 — 实时行情分析

一个无需后端的纯前端股票行情看板，支持实时数据、K 线图、技术分析、热点板块、资金流向。

## 📦 使用方式

### 方式一：双击打开（最简单）
把整个文件夹发给别人，双击 `index.html` 即可打开（部分浏览器可能有限制）。

### 方式二：本地服务器
双击 `start.bat` 自动启动服务器并打开页面。

### 方式三：部署到 GitHub Pages
1. 在 GitHub 上创建一个新仓库
2. 把 `index.html` + `qr-wechat.jpg` + `qr-alipay.jpg` 上传
3. 仓库 Settings → Pages → 选择 main 分支
4. 等待几分钟，访问 `https://你的用户名.github.io/仓库名`

## 🔧 功能
- 大盘指数（上证/深证/创业板/科创50）
- 热点板块 + 成分股联动
- K 线图 + MACD/RSI/KDJ/BOLL 技术指标
- 主力资金流向排行
- 实时快讯（36氪 RSS）
- 自选股管理（本地存储）
- 全量 A 股搜索（约 2900 只）
- 手机响应式布局
- 微信/支付宝捐赠

## 📡 数据来源
- 腾讯财经 API（实时行情）
- 东方财富 API（K 线、板块、资金流）
- 36氪 RSS（新闻快讯）
